Pyidaungsu Regular and Bold 2.5.3, copyright (c) 2014 MCF.
These original TTF files are bundled under the SIL Open Font License 1.1;
see `OFL.txt`. Filenames are shortened; the fonts themselves are unmodified.

- Official download: https://mcf.org.mm/pyidaungsu-font
- Licensing: https://mmunicode.org.mm/fonts/

The app serves both weights locally. It does not depend on an installed
system font or make requests to a third-party font service.
