# အလုပ်လျှောက် — မြန်မာ / English CV ဖန်တီးရန်

ပေးထားသည့်နမူနာများကို အခြေခံထားသော မြန်မာ / English CV website ဖြစ်သည်။ React၊ TypeScript နှင့် Vite ကို အသုံးပြုပြီး backend၊ server database နှင့် API key မလိုပါ။ Developed by **ZinKoLyn**။

## ပါဝင်သည့်လုပ်ဆောင်ချက်များ

- ဖောင်ဖြည့်ခြင်းကို အဓိကထားသည့် ရိုးရှင်းသောအပြင်အဆင်။ ထပ်နေသောအလှဆင်ခေါင်းစဉ်နှင့်စာသားများကို လျှော့ပြီး အလင်း/အမှောင် နှစ်မျိုးလုံးတွင် ကြားနေအရောင်များ၊ ရှင်းလင်းသောခလုတ်နှင့် ဖတ်ရလွယ်သောစာလုံးများကို သုံးထားသည်။ CV စာရွက်နှင့် PDF ပုံစံကို မပြောင်းပါ။
- မွေးသက္ကရာဇ်ကို ရက်၊ လအမည်၊ နှစ် သီးခြားရွေးနိုင်သည်။ လအလိုက်ရက်အရေအတွက်၊ ရက်ထပ်နှစ်နှင့် ယနေ့ထက်နောက်ကျသောရက်ကို စစ်ပေးပြီး CV/PDF ထဲတွင် ရက် / လ / နှစ် အစဉ်အတိုင်း ပြသည်။ မပြည့်စုံသောမွေးသက္ကရာဇ်ရှိလျှင် PDF မထုတ်မီ ပြည့်စုံအောင်ရွေးရန် သို့မဟုတ် ရက်စွဲကိုဖျက်ထားရန် အသိပေးသည်။
- ဖောင်အညွှန်း၊ ခလုတ်နှင့် privacy ရှင်းလင်းချက်များကို ကြီးမားဖတ်ရလွယ်အောင် ပြထားသည်။ ဖုန်းပေါ်က ဖောင်ထည့်သွင်းရာနေရာများကို 16 px၊ အဓိကအညွှန်းကို 14–15 px၊ ရှင်းလင်းချက်များကို အနည်းဆုံး 12–14 px သုံးထားသည်။
- Website အမည် **အလုပ်လျှောက်**၊ မြန်မာ / English interface နှင့် CV စာရွက်ဘာသာစကားကို သီးခြားရွေးချယ်နိုင်သည့် ဝဘ်ဆိုက်ဆက်တင်။ ဘာသာစကားပြောင်းလျှင် ဖြည့်ထားသည့်စာ၊ ဓာတ်ပုံနှင့်တွဲဖက်ဖိုင်များ မပြောင်းပါ။
- Website ဘာသာစကားကို မြန်မာ / ဗြိတိန်အလံနှင့် ဘာသာစကားအမည်တွဲပြီး ရွေးနိုင်သည်။ Website နှင့် CV ဘာသာစကားရွေးချယ်မှုနှစ်ခုလုံးကို workspace အပေါ်ဆုံးတွင် ပြထားသည်။ Footer အပိုင်းတွင် **Developed by ZinKoLyn** နှင့် privacy ခလုတ် ပါဝင်သည်။
- Light / Dark / System theme။ UI theme သာ ပြောင်းလဲပြီး A4 နမူနာ၊ ထုတ်ထားသည့် PDF နှင့်စာရွက်စာတမ်းပုံများမှာ အဖြူရောင်စာရွက်အတိုင်းဖြစ်သည်။
- ပထမအကြိမ်ဝင်လျှင် privacy အကြောင်းရှင်းပြသော dialog ကို ပြသည်။ ဖတ်ရှုနားလည်ကြောင်း ရွေးပြီး သဘောတူမှ CV workspace ကို mount လုပ်သည်။ သဘောမတူမီ မူကြမ်းနှင့်စာရွက်စာတမ်း storage ကို မဖတ်၊ မပြင်ပါ။ Escape ဖြင့် ကျော်၍မရပါ။ သဘောမတူလျှင် ဖောင်ကို ပိတ်ထားပြီး မူလဒေတာကို မပြောင်းပါ။
- နောက်ဆုံးပို့ထားသည့်စာရွက်နှင့်ဆင်တူသော ဘောင်ပါဖောင်ပုံစံ၊ ရိုးရှင်းသောပုံစံ၊ ခေတ်မီသောပုံစံ။
- Website၊ A4 နမူနာနှင့် PDF တို့တွင် project နှင့်အတူပါဝင်သော Pyidaungsu Regular / Bold font ကို အသုံးပြုထားသည်။
- ကိုယ်ရေး၊ လျှောက်ထားမည့်ရာထူးနှင့်ရက်စွဲ၊ ပညာရေး၊ ဘာသာစကား၊ အတွေ့အကြုံ၊ မိသားစုနှင့်ဆက်သွယ်ရန်အချက်အလက်များ။ အသက်မဖြည့်ထားလျှင် မွေးသက္ကရာဇ်မှ တွက်ပေးသည်။
- JPG / PNG / WebP ဓာတ်ပုံထည့်နိုင်သည်။ 8 MB အထိ လက်ခံပြီး browser အတွင်း အရွယ်အစားလျှော့သိမ်းသည်။
- တိုက်ရိုက်နမူနာ၊ မဖြည့်ထားသောအကွက်များဖျောက်ခြင်း၊ စာရှည်ပါက A4 စာမျက်နှာများအလိုက် ခွဲခြင်း။
- PDF ဒေါင်းလုဒ်၊ ပုံနှိပ်ခြင်း၊ ဖုန်းနှင့်ကွန်ပျူတာ နှစ်မျိုးလုံးအတွက် အပြင်အဆင်။
- မှတ်ပုံတင်အရှေ့/အနောက်ကို A4 ဒေါင်လိုက်တစ်မျက်နှာတွင် အပေါ်/အောက် ထည့်ခြင်း၊ အိမ်ထောင်စုစာရင်းကို A4 အလျားလိုက်တစ်မျက်နှာအပြည့် ထည့်ခြင်း။
- ဘွဲ့နှင့်အောင်လက်မှတ် ပုံများ / PDF စာမျက်နှာအားလုံးကို CV နောက်တွင် တွဲထုတ်ခြင်း။ ပုံအလှည့်၊ စာမျက်နှာအစီအစဉ်၊ ဒေါင်လိုက်/အလျားလိုက် ရွေးနိုင်သည်။
- စာရွက်စာတမ်း တစ်ဖိုင် 20 MB၊ စုစုပေါင်း ပုံ / PDF စာမျက်နှာ ၂၀ အထိ ထည့်နိုင်သည်။ ပုံများကို မဖြတ်ဘဲ အံဝင်အောင်ပြပြီး ဖတ်ရလွယ်စေရန် 2400 px အထိ ပြင်ဆင်သည်။

## စက်ပေါ်တွင် ဖွင့်ရန်

Node.js 24 ဖြင့် စမ်းသပ်ထားသည်။

```sh

npm run dev
```

Terminal တွင်ဖော်ပြသည့် လိပ်စာကို ဖွင့်ပါ။ ပုံမှန်လိပ်စာမှာ `http://localhost:5173` ဖြစ်သည်။

```sh
npm run build
npm run preview
```

## ယာယီအချက်အလက် သိမ်းဆည်းပုံ

Privacy သဘောတူထားမှုကို `alote-shauk.privacy-consent.v1` sessionStorage key တွင် မှတ်ထားပြီး tab အသစ်တွင် ပြန်မေးသည်။ ဘာသာစကားနှင့် theme ကိုသာ `alote-shauk.preferences.v1` localStorage key တွင် မှတ်ထားသည်။ ထို preference ထဲတွင် ကိုယ်ရေးဒေတာ မပါပါ။ Website ဆက်တင်ပြောင်းလဲမှုနှင့် privacy gate က မူလ `patama.cv.draft.v1` မူကြမ်း key ကို ပြောင်းမထားပါ။

CV အချက်အလက်နှင့်ကိုယ်ရေးဓာတ်ပုံကို မူလ `patama.cv.draft.v1` sessionStorage key ဖြင့် ဆက်လက်သိမ်းသည်။ ရှိပြီးသားမူကြမ်းကို ပြောင်းလဲခြင်း၊ ဖျက်ခြင်း မလုပ်ပါ။ တွဲဖက်စာရွက်စာတမ်းများကို ပိုမိုကြီးမားသော browser IndexedDB အတွင်း သီးခြားယာယီသိမ်းပြီး sessionStorage ထဲက tab တစ်ခုချင်းစီ၏ random token ဖြင့်သာ ပြန်ဖွင့်သည်။ Server သို့ CV နှင့်စာရွက်စာတမ်းအချက်အလက်များ မပို့ပါ။ Analytics၊ external font request နှင့် server database မပါဝင်ပါ။

Privacy dialog တွင် developer က ဖောင်အကြောင်းအရာနှင့်စာရွက်စာတမ်းများကို စုဆောင်း၊ အသုံးပြု၊ မျှဝေ၊ ရောင်းချခြင်း မပြုကြောင်း ရှင်းပြထားသည်။ ပုံမှန် hosting ချိတ်ဆက်မှု metadata (IP / request logs) ကိုတော့ hosting provider က ကိုင်တွယ်နိုင်ကြောင်းလည်း တိတိကျကျ ဖော်ပြထားပြီး [Vercel Privacy Notice](https://vercel.com/legal/privacy-notice) ကို ချိတ်ထားသည်။ “မည်သည့်ဒေတာကိုမျှ မသိမ်း” ဟု မမှန်ကန်သော ကတိမပေးပါ။

- Refresh လုပ်လျှင် တူညီသော tab အတွင်း မူကြမ်းကို ပြန်ရနိုင်သည်။
- နောက်ဆုံးပြင်ဆင်ပြီး ၂ နာရီကြာပါက မူကြမ်းကို ဖျက်သည်။ ဖွင့်ထားဆဲ tab ကို ၁၅ စက္ကန့်တစ်ကြိမ်၊ ပြန်ကြည့်သည့်အခါနှင့် ပြန်ဖွင့်သည့်အခါ စစ်ဆေးသည်။
- Tab ပိတ်လျှင် ပုံမှန်အားဖြင့် မူကြမ်း ပျက်သည်။ Browser ၏ “Restore closed tab” လုပ်ဆောင်ချက်က session ကို ပြန်ရနိုင်သောကြောင့် ချက်ချင်းဖျက်လိုလျှင် “အသစ်စရန်” ကို နှိပ်ပါ။
- Browser က storage ပိတ်ထားလျှင် ဖွင့်ထားသည့်အချိန်အတွင်းသာ အချက်အလက်ကို သိမ်းထားပြီး အသိပေးသည်။
- စာရွက်စာတမ်းများလည်း နောက်ဆုံးပြင်ဆင်ပြီး ၂ နာရီကြာလျှင် သက်တမ်းကုန်သည်။ ဖွင့်ထားဆဲ app တွင် CV နှင့်အတူ ရှင်းလင်းပြီး၊ ပိတ်ထားသော tab ၏ သက်တမ်းကုန်ဖိုင်များကို နောက် app ပြန်ဖွင့်ချိန်တွင် ရှင်းလင်းသည်။ IndexedDB သည် browser ထဲတွင်ကျန်နိုင်သောကြောင့် ချက်ချင်းရှင်းလင်းလိုပါက “အသစ်စရန်” ကို အသုံးပြုပါ။
- IndexedDB ကို ပိတ်ထားလျှင် စာရွက်စာတမ်းများကို memory ထဲတွင်သာ ထားပြီး အသိပေးသည်။ CV မူကြမ်း၏ မူလသိမ်းဆည်းမှုကို ဆက်လုပ်သည်။
- ဒေါင်းလုဒ်ရယူပြီးသော PDF ကို website က အလိုအလျောက် မဖျက်နိုင်ပါ။

ဖောင်ပုံစံမှာ နောက်ဆုံးပို့ထားသည့်စာရွက်၏အကွက်များကို အသုံးပြုသည်။ မိသားစုအချက်အလက် အပြည့်အစုံကို ဖော်ပြလိုပါက “ရိုးရှင်း” သို့မဟုတ် “ခေတ်မီ” ပုံစံကို ရွေးပါ။

## Vercel ပေါ်တင်ရန်

`vercel.json` တွင် build၊ output နှင့် security header များ ပြင်ဆင်ထားသည်။ Environment variable မလိုပါ။

### CLI ဖြင့်

```sh
npx vercel login
npx vercel --prod
```

မေးလာလျှင် project အမည်ရွေးပြီး လက်ရှိ folder `.` ကို အသုံးပြုပါ။

### GitHub မှတစ်ဆင့်

Project ကို မိမိ GitHub repository သို့တင်ပြီး Vercel တွင် **Add New → Project** မှ import လုပ်ပါ။

| Setting               | Value           |
| --------------------- | --------------- |
| Framework Preset      | Vite            |
| Install Command       | `npm ci`        |
| Build Command         | `npm run build` |
| Output Directory      | `dist`          |
| Environment Variables | မလိုပါ          |

Official deployment guide: https://vite.dev/guide/static-deploy.html#vercel

Playwright က အချက်အလက်ဖြည့်ခြင်း၊ မူကြမ်းပြန်ရခြင်း၊ tab သီးခြားဖြစ်ခြင်း၊ သက်တမ်းကုန်ခြင်း၊ storage မရသည့်အခြေအနေ၊ ဓာတ်ပုံ၊ ပုံစံပြောင်းခြင်း၊ ဖျက်ခြင်း၊ A4 PDF၊ စာမျက်နှာခွဲခြင်းနှင့် ဖုန်းအပြင်အဆင်တို့ကို စစ်သည်။ Screenshot နှင့် နမူနာ PDF များကို `test-results/` အတွင်း ရရှိသည်။

တွဲဖက်စာရွက်စာတမ်းများအတွက် ရှိပြီးသား CV ဒေတာမပြောင်းခြင်း၊ refresh ပြီး ပြန်ရခြင်း၊ tab တစ်ခုချင်းသီးခြားဖြစ်ခြင်း၊ မှတ်ပုံတင်နှစ်ဖက် တစ်မျက်နှာတည်းဖြစ်ခြင်း၊ အလျားလိုက်/ဒေါင်လိုက် PDF အရွယ်အစား၊ စာမျက်နှာစုံ PDF ထည့်ခြင်း၊ လှည့်/ရွှေ့/ဖယ်ခြင်း၊ သက်တမ်းကုန်ခြင်းနှင့် IndexedDB fallback တို့ကိုလည်း စစ်သည်။ `tests/fixtures/` ထဲက ပုံများမှာ အစစ်အမှန်ပုဂ္ဂိုလ်ရေးအချက်အလက် မပါသော စမ်းသပ်ပုံများဖြစ်သည်။

PDF ဖတ်ရန် Mozilla PDF.js ကို browser အတွင်းသာ အသုံးပြုသည်။ Worker၊ CMap နှင့် standard font ဖိုင်များကို site နှင့်အတူ ထည့်ထားသည်။ စကားဝှက်ပါသော PDF ဖိုင်များကို မလက်ခံပါ။

PDF ဒေါင်းလုဒ်တွင် မြန်မာစာနှင့်ပုံစံ မလွဲစေရန် စာမျက်နှာကို high-resolution image အဖြစ် PDF ထဲသို့ ထည့်ထားသည်။ စာသားကို ရွေးကူး၍ရသော PDF လိုပါက ပရင်တာသင်္ကေတမှ **Save as PDF** ကို အသုံးပြုနိုင်သည်။

Font license နှင့် မူလရင်းမြစ်များကို `public/fonts/` တွင် ထည့်ထားသည်။
